Premiere Hebrew Transcriber

תמלול חומרי גלם בעברית, ישר לתוך הקליפ.

פאנל לפרמייר שמזהה לבד את הערוץ הנקי, מתמלל בעברית ומכניס את התמלול לפאנל Text, עם שמות דוברים ותזמונים מדויקים. גוררים קליפים, לוחצים, ועורכים לפי טקסט.

הורדה

ככה זה נראה

43 שניות על מה הפאנל עושה.

מה הוא עושה

כל מה שצריך כדי לעבור מחומרי גלם לעריכה לפי טקסט, בלי לייצא ולייבא קבצים ידנית.

ערוץ נקי, אוטומטית

מנתח את כל ערוצי האודיו ובוחר את המיקרופון הצמוד, לא את מיקרופון המצלמה.

שמות דוברים

כמה מיקרופונים בקליפ? כל ערוץ מקבל שם, והתמלול מסומן לפי מי שדיבר.

תור לקליפים רבים

גוררים קליפים או בוחרים "כל מה שאין לו תמלול", ומתמללים כמה במקביל.

תזמונים מדויקים

קצוות המילים מיושרים לשקטים באודיו, כך שחיתוך לפי טקסט נופל במקום.

ענן או מקומי

HappyScribe, ElevenLabs, או מודל ivrit.ai שרץ במחשב בחינם, בלי שהחומר יוצא ממנו.

ישר לפאנל Text

התמלול נכנס לקליפ עצמו, בקטעים של עד 20 שניות. אפשר לחפש, לסמן ולערוך לפי טקסט.

איך זה עובד

הקלטה מתוך פרמייר: מהגרירה מפאנל הפרויקט, דרך התמלול, ועד הטקסט בעברית בפאנל Text.

  1. גוררים קליפים לפאנל

    ישר מפאנל הפרויקט. אפשר גם לבחור כל מה שאין לו תמלול.

  2. הפאנל מכין את התור

    בוחר לכל קליפ את הערוץ הנקי, ומדלג על קליפים שכבר יש להם תמלול.

  3. לוחצים התחל תמלול

    כשהתור מסתיים, התמלול כבר בתוך הקליפ. פותחים את פאנל Text ועורכים לפי טקסט, עם שמות דוברים ותזמונים.

התקנה

כמה דקות, בלי להתקין שום תוכנה נוספת.

  • מק עם מעבד Apple, מ-M1 ומעלה
  • Premiere Pro 25.6 ומעלה
  • כ-2GB פנויים לתמלול מקומי
  1. להוריד את הקובץ ולסגור את פרמייר

    הקובץ PremiereTranscriber-mac.ccx מהכפתור למעלה.

  2. ללחוץ לחיצה כפולה על הקובץ

    Creative Cloud יפתח חלון התקנה. אם מופיעה אזהרה שהתוסף לא מגיע מ-Adobe, זה צפוי ואפשר לאשר.

  3. לפתוח את הפאנל בפרמייר

    בתפריט Window → UXP Plugins → Premiere Hebrew Transcriber. כדאי לעגן אותו ליד פאנל הפרויקט ולשמור את ה-Workspace.

  4. לאשר הפעלה בפעם הראשונה

    הפאנל מפעיל ברקע תוכנת עזר קטנה, שעולה רק כשהפאנל פתוח ונסגרת לבד.

    • אם פרמייר שואל אם להפעיל אותה: לאשר ולסמן שיזכור.
    • אם macOS חוסם אותה: System Settings → Privacy & Security, לגלול למטה וללחוץ Open Anyway.

    כשהכול תקין, בראש הפאנל כתוב מחובר.

  5. לבחור תיקיית עבודה ושירות תמלול

    בהגדרות: בלשונית תיקיות וקבצים לבחור תיקייה, ובלשונית שירותי תמלול להדביק מפתח API או להוריד מודל מקומי. המפתחות נשמרים ב-Keychain של המק.

  6. לגרור קליפים ולתמלל

    לגרור קליפים מפאנל הפרויקט לפאנל וללחוץ התחל תמלול. אם הקבצים על כונן חיצוני, macOS ישאל פעם אחת אם לאפשר גישה.

  • Windows 10 או 11, 64 ביט
  • Premiere Pro 25.6 ומעלה
  • לתמלול מקומי: מעבד משנת 2013 ומעלה
  1. להוריד את הקובץ ולסגור את פרמייר

    הקובץ PremiereTranscriber-win.ccx מהכפתור למעלה.

  2. ללחוץ לחיצה כפולה על הקובץ

    Creative Cloud יפתח חלון התקנה. אם מופיעה אזהרה שהתוסף לא מגיע מ-Adobe, זה צפוי ואפשר לאשר.

  3. לפתוח את הפאנל בפרמייר

    בתפריט Window → UXP Plugins → Premiere Hebrew Transcriber. כדאי לעגן אותו ליד פאנל הפרויקט ולשמור את ה-Workspace.

  4. לאשר הפעלה בפעם הראשונה

    הפאנל מפעיל ברקע תוכנת עזר קטנה (PremiereTranscriberHelper.exe), שלא פותחת חלון ונסגרת לבד.

    • אם פרמייר שואל אם להפעיל אותה: לאשר ולסמן שיזכור.
    • אם מופיע מסך כחול Windows protected your PC: ללחוץ More info ואז Run anyway.
    • אם אנטי-וירוס חוסם אותה: לאשר אותה בתוכנה.

    כשהכול תקין, בראש הפאנל כתוב מחובר.

  5. לבחור תיקיית עבודה ושירות תמלול

    בהגדרות: בלשונית תיקיות וקבצים לבחור תיקייה, ובלשונית שירותי תמלול להדביק מפתח API או להוריד מודל מקומי. המפתחות נשמרים במנהל האישורים של Windows.

  6. לגרור קליפים ולתמלל

    לגרור קליפים מפאנל הפרויקט לפאנל וללחוץ התחל תמלול.

חינם ופרטי

מה חדש

הגרסה האחרונה

  • הגדרות שנפתחות מיד, עם גלילה ולשונית "אודות".
  • גרסה ראשונה ל-Windows.

שאלות נפוצות

בראש הפאנל כתוב "לא מחובר"

מערכת ההפעלה או אנטי-וירוס חסמו את תוכנת העזר. חוזרים לשלב 4 בהתקנה, סוגרים ופותחים את הפאנל. אם זה לא עוזר, שולחים את קובץ היומן (ראו למטה).

לקליפ כבר יש תמלול

הפאנל לא דורס תמלול קיים. כדי לתמלל שוב מסמנים תמלל גם קליפים מתומללים, ואז מייבאים את הקובץ מתיקיית העבודה דרך Text → … → Import Transcript. פעולה זו אפשר לבטל עם Cmd+Z או Ctrl+Z.

איפה נשמרים הקבצים?

רק בתיקיית העבודה שבוחרים בהגדרות, בתיקייה לכל פרויקט ולכל קליפ. אפשר לבחור שקובצי האודיו יימחקו אחרי תמלול מוצלח, כדי לחסוך מקום.

מה עם פרטיות?

האודיו נשלח רק לשירות שבחרת. בתמלול מקומי הוא לא יוצא מהמחשב. תוכנת העזר זמינה רק מתוך המחשב עצמו, ומפתחות ה-API נשמרים במאגר הסיסמאות של המערכת.

איך מעדכנים לגרסה חדשה?

מורידים את הקובץ החדש מהדף הזה ופותחים אותו. Creative Cloud מחליף את הגרסה הקיימת, וההגדרות נשמרות. הגרסה המותקנת מופיעה בהגדרות של הפאנל.

מה לשלוח אם משהו לא עובד?

צילום מסך של הפאנל, גרסת המערכת, ואת קובץ היומן:

  • Mac: ~/Library/Logs/premiere-transcriber.log
  • Windows: %LOCALAPPDATA%\Premiere Transcriber\helper.log
